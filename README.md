# El Gerente

Plataforma de administración para pequeños negocios, apoyada con IA.

## Objetivo

Permitir al propietario de un negocio pequeño administrar todo lo relacionado con su operación de manera fácil y rápida, usando herramientas de inteligencia artificial para tareas como lectura de facturas, manejo de inventario y registro de transacciones internas.

## Estructura de análisis

```
analysis/
  00-vision/          # Visión general, usuarios, alcance
  01-features/        # Definición de features y módulos
  02-architecture/    # Decisiones técnicas y arquitectura
  03-ux/              # Flujos de usuario, wireframes, UX
  04-data-model/      # Modelo de datos

  superpowers/

```
